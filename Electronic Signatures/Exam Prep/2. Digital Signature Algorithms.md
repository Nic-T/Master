# Digital Signature Algorithms

## 1. RSA (Rivest–Shamir–Adleman)

RSA is widely used for encryption and signatures. Security is based on the Integer Factorization Problem.

- Hard Problem: Factoring a large composite $n = p \times q$ into its prime factors $p$ and $q$ is computationally infeasible.
- Key generation:
  1.  Generate large primes $p$ and $q$.
  2.  Compute modulus $n = p\times q$ and totient $\Phi(n) = (p-1)(q-1)$.
  3.  Choose public exponent $e$ with $1 < e < \Phi(n)$ and $\gcd(e,\Phi(n)) = 1$.
  4.  Compute private exponent $d$ such that $d\times e \equiv 1 \; (\bmod\; \Phi(n))$.

- Public key: $(n, e)$
- Private key: $(n, d)$

- Signing / Verification (simplified):
  - Signing: compute $s = H(m)^d \; (\bmod\; n)$.
  - Verification: check $H(m)' = s^e \; (\bmod\; n)$ matches $H(m)$.

## 2. DSA (Digital Signature Algorithm)

DSA (NIST) is dedicated to signatures; security is based on the Discrete Logarithm Problem (DLP).

- Key components: large prime $p$, prime divisor $q$ of $(p-1)$, generator $g$.
- Private key $x$ in $[1, q-1]$; public key $y = g^x \; (\bmod\; p)$.
- Critical: a fresh random $k$ must be used for every signature; reuse or poor randomness leaks the private key.
- Signature output: pair $(r, s)$.

## 3. ECC (Elliptic Curve Cryptography) & ECDSA

ECC provides equivalent security to RSA with much smaller key sizes.

- Hard problem: Elliptic Curve Discrete Logarithm Problem (ECDLP). Given points $P$ and $Q=k\cdot P$, deriving $k$ is infeasible.
- Curve equation (short Weierstrass): $y^2 = x^3 + a x + b$.
- Group operations: point addition and doubling.
- ECDSA: analogous to DSA; produces signature pair $(r, s)$ and requires a cryptographically secure random $k$.
- ECDH: key agreement producing shared secret $K = n_A \cdot P_B = n_B \cdot P_A$.

## Key Size Cheat Sheet

Approximate equivalent security levels:

- AES / RSA / ECC
  - 80-bit: AES-80 ≈ RSA-1024 ≈ ECC-160
  - 112-bit: AES-112 ≈ RSA-2048 ≈ ECC-224
  - 128-bit: AES-128 ≈ RSA-3072 ≈ ECC-256
  - 256-bit: AES-256 ≈ RSA-15360 ≈ ECC-512

Key takeaway: ECC 256-bit ≈ RSA 3072-bit.
