# Symmetric vs. Asymmetric Cryptography

The lecture material emphasizes the trade-offs between speed and key management, and the mathematical foundations of these systems.

## Symmetric Key Cryptography

- Mechanism: Uses the same key to encrypt and decrypt data.
- Performance: Computationally fast — suitable for large data volumes.
- Algorithms:
  - DES (Data Encryption Standard): Older block cipher with a 56-bit key and 64-bit block size; based on a Feistel network.
  - AES (Advanced Encryption Standard / Rijndael): Supports 128/192/256-bit keys (authors: Joan Daemen, Vincent Rijmen).
- Security note: Brute force is the primary attack; AES-256 is considered practically unbreakable by brute force.

## Asymmetric Key Cryptography

- Mechanism: Uses a pair of related keys — a public key (published) and a private key (secret).
- Performance: Slower than symmetric cryptography; used for key exchange, signatures, and small payload encryption.
- Hard problems:
  - RSA: Integer Factorization Problem.
  - Diffie–Hellman (DH) / DSA: Discrete Logarithm Problem.
  - ECC (Elliptic Curve Cryptography): Elliptic Curve Discrete Logarithm Problem (ECDLP).

## Hash Functions

Hash functions are critical for digital signatures and integrity. Key properties:

- Deterministic: Same input → same hash.
- Efficient: Quick to compute.
- Irreversible: Infeasible to recover the input from the hash.
- Collision resistant: Hard to find two distinct inputs with the same hash.
- Avalanche effect: Small input changes cause large, unpredictable hash changes.

Teacher's analogy: "You can cook a cow into a burger, but you cannot heal back the burger into a cow." Use secure hashes — weak hashes compromise signatures.

## Security Services

- Confidentiality: Provided by encryption (symmetric/asymmetric).
- Integrity: Provided by hash functions and digital signatures.
- Authentication: Provided by digital signatures and encryption.
- Non-repudiation: Provided by digital signatures (private-key unique to signer).

## Key Size Comparisons (Cheat Sheet)

Equivalent security levels (approximate):

- Symmetric (AES) / RSA / ECC
  - 80-bit: AES-80 ≈ RSA-1024 ≈ ECC-160
  - 112-bit: AES-112 ≈ RSA-2048 ≈ ECC-224
  - 128-bit: AES-128 ≈ RSA-3072 ≈ ECC-256
  - 256-bit: AES-256 ≈ RSA-15360 ≈ ECC-512

Note: ECC provides much shorter keys for equivalent security (e.g., 256-bit ECC ≈ 3072-bit RSA).
