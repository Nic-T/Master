# 2. Network layer security (IPSec)

## Overview ✅

- **Layer:** Network (Layer 3)
- **Purpose:** Secure IP packets end-to-end or between gateways
- **Core components:** `AH`, `ESP`, `IKE`

---

## Protocols

- `AH` (Authentication Header) — Protocol 51
  - Provides **data integrity** and **origin authentication**
  - **Does NOT** provide confidentiality (no encryption)
  - Protects payload + immutable IP header fields

- `ESP` (Encapsulating Security Payload) — Protocol 50
  - Provides **confidentiality (encryption)**, integrity, and origin authentication
  - Protects payload in **transport mode** or entire packet in **tunnel mode**

---

## Modes of operation

1. **Transport mode**
   - Protects **payload only**; original IP header remains
   - Typical for **host-to-host** communication

2. **Tunnel mode**
   - Encrypts the **entire original IP packet** and adds a new IP header
   - Typical for **gateway-to-gateway** (VPNs)

---

## Key management

- `IKE` (Internet Key Exchange)
  - Automates key exchange; uses UDP port **500**
  - Uses Diffie–Hellman for establishing shared secrets

- `SA` (Security Association)
  - A contract defining keys/algorithms; identified by an **SPI** (Security Parameters Index)

---

## Quick exam tips 💡

- **AH ≠ encryption**, **ESP = encryption**.
- **Transport = payload only**, **Tunnel = whole packet**.
- Remember: `IKE` runs on UDP/500 and establishes the `SA`.
