# 5. Security standards

## Key organizations & what they publish ✅

- **IETF** (Internet Engineering Task Force)
  - Publishes **RFCs** that specify Internet protocols (e.g., TLS, IPSec)

- **ITU‑T**
  - Creates **X.** standards, notably **X.509** (digital certificates) and **X.500** (directories)

- **NIST** (National Institute of Standards and Technology)
  - Publishes **FIPS** (Federal Information Processing Standards) — e.g., **FIPS 140** (crypto modules), **FIPS 197** (AES)

- **RSA Labs**
  - Publishes **PKCS** standards (PKCS#1, PKCS#11, PKCS#12)

---

## Quick exam tips 💡

- Map the standard to the organization (e.g., **X.509 → ITU‑T**, **FIPS → NIST**, **RFC → IETF**).
- Remember common FIPS and PKCS numbers used in questions.

## Abbreviations glossary 📖

- **AES** — Advanced Encryption Standard
- **FIPS** — Federal Information Processing Standards
- **IETF** — Internet Engineering Task Force
- **IPSec** — Internet Protocol Security
- **ITU-T** — International Telecommunication Union - Telecommunication Standardization Sector
- **NIST** — National Institute of Standards and Technology
- **PKCS** — Public Key Cryptography Standards
- **RFC** — Request for Comments
- **RSA** — Rivest-Shamir-Adleman (inventors' names)
- **TLS** — Transport Layer Security
