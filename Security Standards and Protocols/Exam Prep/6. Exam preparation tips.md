# 6. Exam preparation tips

## High‑value study points ✅

- **Distinguish AH vs ESP**: AH = integrity/authentication only; ESP = encryption (+ integrity).
- **Transport vs Tunnel**: Transport = payload only (host-to-host); Tunnel = entire packet (gateway-to-gateway).
- **Trust models**: PGP = Web of Trust (peer signatures); S/MIME = PKI (CA, X.509).
- **Authentication factors**: Be able to classify any example quickly (knowledge, possession, inherence).
- **Symmetric vs Asymmetric**: Symmetric (fast, bulk — AES/DES). Asymmetric (key exchange, signatures — RSA/DH).

---

## Quick mnemonics & tips 🧠

- "PAP = Plaintext" (insecure)
- "Kerberos = KDC + Tickets + Time"
- FAR/FRR/EER — think **accept vs reject** tradeoff (EER = balance point)

- **DES** — Data Encryption Standard
- **DH** — Diffie-Hellman
- **EER** — Equal Error Rate
- **ESP** — Encapsulating Security Payload
- **FAR** — False Acceptance Rate
- **FRR** — False Rejection Rate
- **KDC** — Key Distribution Center
- **PAP** — Password Authentication Protocol
- **PGP** — Pretty Good Privacy
- **PKI** — Public Key Infrastructure
- **RSA** — Rivest-Shamir-Adleman
- **S/MIME** — Secure/Multipurpose Internet Mail Extensions
